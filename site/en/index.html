Escriba de la Marca

A PWA for collectors of the Spanish tabletop RPG Aventuras en la Marca del Este. Scan a barcode and it tells you whether you already own the book and what is missing from each series.

  • 118 publications
  • 83 authors
  • 83 searchable adventures

Development

  • Vanilla JavaScript PWA, no framework, no build step
  • Continuous barcode scanner
  • Community catalogue with quests and levels
  • PostgreSQL with row-level security

Operations

  • CI/CD with GitHub Actions to GitHub Pages
  • 200 tests: pgTAP + Playwright
  • Scheduled jobs with pg_cron and Telegram alerts
  • Supabase: €0 infrastructure cost

OSR Manager

A table assistant for old-school RPG game masters: exploration, hexcrawl, encounters, combat, light and resources. Runs in the browser and fully offline.

Development

  • Custom dice engine, no eval
  • Per-campaign rulesets: base + overrides
  • Statblock importer from plain text
  • 7 systems: OSE, B/X, BECMI, LotFP…

Operations

  • Zero dependencies, zero backend
  • Works offline from file://
  • Releases as a portable ZIP
  • Landing page and app on GitHub Pages
