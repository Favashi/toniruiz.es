OSR Manager

Ayuda de mesa para directores de juego de rol clásico: exploración, hexcrawl, encuentros, combate, luz y recursos. Funciona en el navegador y sin conexión.

Desarrollo

  • Motor de dados propio, sin eval
  • Reglas por campaña: base + overrides
  • Importador de statblocks desde texto
  • 7 sistemas: OSE, B/X, BECMI, LotFP…

Operaciones

  • Cero dependencias, cero backend
  • Funciona offline desde file://
  • Releases con ZIP portable
  • Landing y app en GitHub Pages
